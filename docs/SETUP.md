# 安装、设置与使用

仅适用于 HUAWEI WLZ-AN00、Android 12 / API 31、系统构建 WLZ-AN00 4.2.0.121(C00E121R3P3)。其他设备不在兼容范围。本文生成于 2026-11-03T08:26:14+08:00（Asia/Shanghai）。

## 安装和证书

从[公开发布页](https://github.com/Chenyi-1999/gpt-auto-open-net/releases)获取维护者已验证的 APK 与 SHA-256 校验文件，先核对校验值。源码快照本身不表示新的 APK 已完成构建或发布。

安装或更新由用户确认。如果签名不匹配，先核对来源及签名；不要关闭系统安全防护。卸载旧版本会删除 App 内部日志，是否卸载由用户决定。USB 调试仅用于开发安装，不是日常运行依赖。

## 首次设置

1. 打开 App，阅读用途说明后，由用户在系统设置中启用“USB共享辅助服务”，检查服务已连接。
2. 允许应用通知及守护通知类别。通知不可用时守护不能正常启动或会停止。
3. 在 App 内明确启动守护，保留前台持续通知。
4. 如需重启后尝试自动启动，另行启用“开机自动守护”。该选项默认关闭，不代表当前守护立即启动，也不会恢复被撤销的授权。

如系统锁屏或充电画面挡住设置页，用户应自行根据实际手机界面决定如何处理。关闭安全锁会降低手机保护程度；App 不修改锁屏设置、不输入密码、不绕过认证，也不自动同意系统授权或选择 USB 模式。后台运行、自启动或后台弹窗策略如需调整，也只能由用户手动配置；不保证永久运行。

## 停止和日志

首页和通知都提供“停止守护”。显式停止还会关闭开机自动守护并撤销等待；重新使用时需由用户再次启动，并按需重新启用开机选项。要手动关闭 USB 共享时，先停止守护。

日志只保存在手机本地，可在 App 中查看、清空或通过系统文件入口导出；最多 300 行或 256 KiB，旧记录滚动淘汰。导出前自行检查内容；不要在公开 issue 上传未处理的设备或网络日志。卸载前停止守护并关闭辅助服务。

应用更新不触发自行启动。任务移除、权限撤销、系统回收等情况可能停止守护；不要把后台设置当作永久保活保证。手机显示共享开启也不能证明电脑已完整联网，当前 Windows 整体验证仍未完成。详见[测试报告](TEST_REPORT.md)。
