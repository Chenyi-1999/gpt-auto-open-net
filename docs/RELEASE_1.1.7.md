## 功能

守护通过前台通知持续展示状态，只在用户明确启动后工作。默认关闭的开机自动守护是独立选项，显式停止守护同时关闭该选项。

在精确适配的华为系统中，完整匹配已知 USB 连接方式模态时，允许一次受限取消；取消后必须重新读取设置页，遵守原有期限、次数、唯一控件与状态门槛。不会自动选择 USB 模式、同意系统授权或操作未知页面。

兼容范围仅为 HUAWEI WLZ-AN00 / Android 12（API 31）/ WLZ-AN00 4.2.0.121(C00E121R3P3)。无 Root、无安全锁绕过，不承诺永久运行或其他设备兼容。
